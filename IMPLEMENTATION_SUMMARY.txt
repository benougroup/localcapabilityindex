================================================================================
DESIGN PHILOSOPHY
================================================================================

This implementation uses Apple-style scroll interactions while maintaining
maximum compatibility with search engine crawlers and indexing bots:

1. CONTENT-FIRST: All content is in HTML, not generated via JavaScript
2. PROGRESSIVE ENHANCEMENT: Works without JS, enhanced with JS
3. PERFORMANCE-FOCUSED: CSS animations, minimal JS, GPU acceleration
4. BOT-SAFE: No complex scripts that confuse crawlers
5. ACCESSIBLE: Full ARIA support, keyboard navigation, screen readers
6. RESPONSIVE: Works perfectly on all device sizes
7. SEMANTIC: Clean HTML structure, proper heading hierarchy
8. ENTERPRISE: Professional design matching institutional positioning

The scroll animations are triggered by the Intersection Observer API,
which is:
  - Native browser API (no library needed)
  - Supported in all modern browsers (and gracefully degrades)
  - Lightweight and performant
  - Crawler-friendly (content is static, not dynamically injected)
  - No lazy-loading confusion (all content pre-loaded)
